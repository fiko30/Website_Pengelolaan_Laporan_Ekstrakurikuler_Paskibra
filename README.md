# Sistem Informasi & Pengelolaan Laporan Ekstrakurikuler Paskibra (PWA)
### Paskibra Garatika — SMK Negeri 40 Jakarta

Sistem web modern berbasis **Progressive Web App (PWA)** untuk pengelolaan laporan mingguan, presensi latihan, inventarisasi sarana prasarana, keuangan kas, dan publikasi media kreatif Paskibra Garatika SMKN 40 Jakarta.

## 🚀 Fitur Utama
- **Progressive Web App (PWA)**: Dapat diinstal langsung di Android, iOS, Windows, dan MacOS layaknya aplikasi native (dengan dukungan offline caching & icon homescreen).
- **Format Laporan Resmi Berkop Surat**: Generate cetakan dokumen PDF resmi lengkap dengan kop surat sekolah dan lambang Garatika menggunakan jsPDF & AutoTable.
- **Hierarki & Hak Akses Berbasis Peran**:
  - **Ketua Umum**: Hak akses penuh (manajemen laporan, verifikasi, kelola arsip, sinkronisasi Google Drive).
  - **Wakil Ketua & Pelatih**: Mode baca (*read-only*), dapat melihat rincian laporan, mengunduh PDF, dan memantau arsip.
  - **Divisi (Sekretaris, Bendahara, Sarpras, Media Kreatif, Korlap)**: Mengisi dan mengelola laporan spesifik divisinya masing-masing.
- **Integrasi Cloud Google Drive & Google Sheets**: Berkas PDF tersinkronisasi otomatis ke Google Drive via Google Apps Script (GAS) dengan dukungan akses publik (*view-only*).
- **Desain Modern & Responsif**: Tampilan antarmuka yang dioptimalkan untuk desktop hingga smartphone.

## 📱 Instalasi Aplikasi (PWA)
1. Buka tautan website di browser (Chrome / Edge / Safari).
2. Klik ikon **Install App** / **Tambahkan ke Layar Utama** (*Add to Home Screen*).
3. Aplikasi siap digunakan secara mandiri langsung dari layar beranda smartphone atau desktop!
